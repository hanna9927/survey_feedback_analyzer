# survey_feedback_analyzer


## Overview

Survey Feedback Analyzer is a beginner-friendly Python project that analyzes survey feedback stored in a dictionary of lists. It uses basic Python programming concepts to clean text, analyze customer comments, and generate useful insights from survey ratings.

## Features

- Preloaded survey feedback dataset with 10 entries
- Add new feedback entries dynamically
- Automatically generate serial numbers
- Clean text by removing punctuation and extra spaces
- Convert feedback to lowercase
- Count feedback entries containing specific keywords
- Calculate the average rating
- Identify the longest feedback by word count
- Extract unique words from all feedback entries
- Sort feedback entries by rating (optional)

## Technologies Used

- Python
- Lists and Dictionaries
- Loops and Conditional Statements
- User-Defined Functions
- String Manipulation
- Sets and Sorting

## Project Concepts

This project demonstrates basic data cleaning, keyword analysis, descriptive statistics, and text processing using fundamental Python concepts.

## How to Run

1. Install Python 3 if it is not already installed.
2. Clone or download this repository.
3. Open the Python file or Jupyter Notebook.
4. Run the code.
5. Enter the number of additional feedback entries when prompted.
6. View the cleaned feedback data and final insights.

## Sample Insights

The program generates:

- Number of feedback entries containing "good", "poor", and "excellent"
- Average survey rating
- Longest feedback comment by word count
- Alphabetically sorted list of unique words
- Feedback entries sorted by rating (optional)

*Actual results depend on the feedback entries provided during execution.*
